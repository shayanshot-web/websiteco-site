# پنل مدیریت سایت هلیله

## نصب (یک‌بار)
1. در سی‌پنل → File Manager → `public_html` → Upload → فایل `helileh-cms.zip` → روی آن راست‌کلیک → Extract.
   (اگر پرسید فایل‌ها جایگزین شوند، بله؛ `.htaccess` و `contact.php` به‌روز می‌شوند.)
2. سی‌پنل → Select PHP Version → Extensions: `pdo_sqlite`, `sqlite3`, `mbstring`, `fileinfo`, `gd`, `dom` تیک داشته باشند.
3. مرورگر: `https://websiteco.ir/install.php` → نام، نام‌کاربری و رمز مدیر (حداقل ۱۰ نویسه) → «ساخت مدیر و نصب».
4. **فایل `install.php` را از public_html حذف کنید.**
5. ورود: `https://websiteco.ir/admin/`

دیتابیس در پوشه `cms_data` (بالاتر از public_html، در صورت امکان) ذخیره می‌شود؛ از آن بک‌آپ بگیرید. عکس‌ها در `public_html/uploads`.

## کار با پنل
- **نوشته‌ها / محصولات / رویدادها / اقامتگاه‌ها / گالری**: هر مورد سه تب زبان (فارسی، English، Русский) دارد؛ زبانی که عنوانش خالی باشد در همان زبان نمایش داده نمی‌شود.
- **صفحات**: متن بالای صفحه‌های سایت (درباره، اقامت، تجربه‌ها، …) را جایگزین می‌کند؛ لیست‌ها خودکار زیرش می‌آید.
- **کتابخانه رسانه**: آپلود چندتایی، بهینه‌سازی خودکار، متن جایگزین سه‌زبانه. داخل ویرایشگر هم دکمه «🖼 تصویر» دارید.
- **پیام‌ها**: پیام فرم تماس و درخواست‌های سفارش/رزرو (علاوه بر ایمیل) اینجا ذخیره می‌شود.
- **کاربران**: مدیر کل، ویراستار، مدیر فروشگاه و اقامت، نویسنده (نویسنده فقط پیش‌نویس/در انتظار بازبینی می‌فرستد).
- نشانی هر مورد: `/blog/نام/`، `/handicraft-shop/نام/`، `/events/نام/`، `/accommodations/نام/` (در انگلیسی و روسی با پیشوند و اسلاگ همان زبان).
- نقشه سایت موردهای جدید: `https://websiteco.ir/sitemap-cms.xml` (در Search Console ثبت کنید).

## امنیت
رمزها با bcrypt، توکن CSRF روی همه فرم‌ها، کوکی HttpOnly/SameSite، محدودیت تلاش ورود، پاک‌سازی HTML ورودی، آپلود فقط تصویر با بررسی محتوا، اجرای PHP در uploads غیرفعال، و دسترسی وب به cms-core بسته است.
