# راهنمای انتقال سایت هلیله (Next.js) به هاست سی‌پنل

این پروژه سایت دهیاری هلیله است که از صفر با Next.js برنامه‌نویسی شده (بدون وردپرس) و روی دامنه `websiteco.ir` بالا می‌آید (سه زبان: فارسی، انگلیسی، روسی).
خروجی آن **فایل‌های استاتیک HTML** است؛ یعنی روی سی‌پنل **نیازی به Node.js، دیتابیس یا PHP-FPM خاصی نیست** و فقط داخل `public_html` کپی می‌شود. فرم تماس با یک فایل کوچک PHP (`contact.php`) ایمیل می‌فرستد.

آدرس‌ها دقیقاً مثل وردپرس قبلی حفظ شده‌اند (مثلاً `/about/`، `/en/about-us/`، `/ru/o-nas/`)، پس لینک‌ها و سئو به هم نمی‌ریزد.

---

## مرحله ۰ — بک‌آپ از وردپرس فعلی

قبل از هر کاری از سایت و دیتابیس فعلی بک‌آپ کامل بگیرید (از سی‌پنل قدیمی: **Backup → Download a Full Backup**، یا با افزونه Duplicator / UpdraftPlus) و روی کامپیوتر خودتان نگه دارید.
این بک‌آپ شبکه ایمنی شماست؛ تا وقتی سایت جدید را کامل تست نکرده‌اید چیزی را پاک نکنید.

## مرحله ۱ — تنظیم ایمیل مقصد فرم تماس

فایل `public/contact.php` را باز کنید و خط زیر را به ایمیل واقعی دهیاری تغییر دهید:

```php
$TO = 'info@websiteco.ir';
```

(بهتر است ایمیلی روی همان دامنه باشد؛ در سی‌پنل: **Email Accounts → Create**.)

## مرحله ۲ — ساخت سایت روی کامپیوتر خودتان

1. Node.js نسخه ۲۰.۹ یا بالاتر (ترجیحاً ۲۲ LTS) را از nodejs.org نصب کنید.
2. در پوشه پروژه، ترمینال را باز کنید:

```bash
npm install
npm run build
```

3. پوشه **`out`** ساخته می‌شود؛ همین پوشه کل سایت است.
   اگر `npm install` به‌خاطر فیلتر بودن رجیستری خطا داد، از VPN یا یک mirror معتبر npm استفاده کنید.

برای دیدن پیش‌نمایش قبل از آپلود: `npm run dev` و باز کردن `http://localhost:3000`.

## مرحله ۳ — آماده‌سازی هاست جدید (سی‌پنل)

1. وارد سی‌پنل هاست جدید شوید.
2. اگر دامنه `websiteco.ir` هنوز روی این هاست تعریف نشده: **Domains → Create A New Domain** (یا در نسخه‌های قدیمی‌تر **Addon Domains**)، دامنه را اضافه کنید و Document Root را `public_html` بگذارید.
3. در **File Manager** وارد `public_html` شوید.
4. بالا-راست **Settings** را باز کنید و **Show Hidden Files (dotfiles)** را تیک بزنید؛ چون فایل `.htaccess` مخفی است.
5. فایل‌های پیش‌فرض هاست (مثل `index.html` یا پوشه `cgi-bin` خالی) را پاک کنید. اگر روی این هاست فایلی از قبل دارید، اول یک پوشه `old_backup` بسازید و آن‌ها را آنجا منتقل کنید.

## مرحله ۴ — آپلود سایت

1. روی کامپیوتر، **محتوای داخل** پوشه `out` را (نه خود پوشه `out`) ZIP کنید. باید `index.html`، `404.html`، پوشه `_next`، `contact.php` و `.htaccess` بالای ZIP باشند.
2. در File Manager داخل `public_html` روی **Upload** بزنید و ZIP را بفرستید.
3. روی فایل ZIP راست‌کلیک کنید → **Extract** (مسیر: `/public_html`).
4. ZIP را پاک کنید.
5. بررسی کنید که این‌ها در `public_html` هستند: `index.html`, `404.html`, `_next/`, `about/`, `en/`, `ru/`, `contact.php`, `.htaccess`, `sitemap.xml`, `robots.txt`.

> اگر `.htaccess` در خروجی `out` نبود، آن را از `public/.htaccess` پروژه دستی آپلود کنید.

## مرحله ۵ — تست پیش از تغییر DNS

تا وقتی DNS عوض نشده، می‌توانید سایت جدید را این‌طور ببینید:
- از سی‌پنل آدرس موقت (مثل `https://IP-سرور/~نام‌کاربری/`) یا
- فایل `hosts` کامپیوتر خودتان را ویرایش کنید: `IP-سرور-جدید  websiteco.ir www.websiteco.ir`

(با آدرس موقت، ریدایرکت https ممکن است مزاحم شود؛ برای تست می‌توانید دو بلوک `RewriteRule` داخل `.htaccess` را موقتاً کامنت کنید.)

صفحه‌ها را بگردید و فرم تماس را یک بار امتحان کنید.

## مرحله ۶ — انتقال دامنه (DNS)

۱. یک روز قبل، در پنل دامنه TTL رکوردها را روی کمترین مقدار بگذارید (اختیاری، برای انتقال سریع‌تر).
۲. دو راه دارید:
   - **تغییر Name Server:** در پنل ثبت دامنه (برای `.ir` در nic.ir) NSهای هاست جدید را بگذارید (در ایمیل خوش‌آمدگویی هاست آمده).
   - **تغییر رکورد A:** اگر DNS جای دیگری (مثل Cloudflare) مدیریت می‌شود، رکورد A برای `websiteco.ir` و `www` را به IP هاست جدید تغییر دهید.
۳. انتشار تا ۲۴ تا ۴۸ ساعت طول می‌کشد؛ در این مدت ممکن است بعضی کاربران سایت قدیم و بعضی سایت جدید را ببینند. هاست قدیمی را تا پایان این مدت نگه دارید.

## مرحله ۷ — گواهی SSL

وقتی DNS به هاست جدید رسید:
1. سی‌پنل → **SSL/TLS Status**.
2. دامنه و `www` را انتخاب و **Run AutoSSL** را بزنید.
3. پس از صدور، `https://websiteco.ir` را باز کنید. ریدایرکت خودکار به https در `.htaccess` فعال است.

(اگر هاست AutoSSL ندارد: **Let's Encrypt** از بخش SSL/TLS یا از پشتیبانی هاست بخواهید.)

## مرحله ۸ — ایمیل‌ها

اگر ایمیل دامنه‌ای (مثل `info@websiteco.ir`) روی هاست قبلی داشتید، قبل از تغییر DNS آن حساب‌ها را روی هاست جدید بسازید و در صورت نیاز ایمیل‌های قدیمی را با IMAP منتقل کنید؛ در غیر این صورت بعد از تغییر DNS ایمیل‌ها گم می‌شوند.

## مرحله ۹ — بعد از انتقال

- در Google Search Console دامنه را اضافه و `https://websiteco.ir/sitemap.xml` را ثبت کنید.
- بعد از ۴۸ ساعت و اطمینان از کارکرد کامل، هاست قبلی را تعطیل کنید (بک‌آپ مرحله ۰ را نگه دارید).

## ویرایش محتوا بعد از انتقال

چون وردپرس حذف می‌شود، متن‌ها در فایل‌های زیر هستند:

| زبان | فایل |
|---|---|
| فارسی | `src/content/fa.ts` |
| انگلیسی | `src/content/en.ts` |
| روسی | `src/content/ru.ts` |

متن‌هایی که در وردپرس داخل `[ ... ]` بودند (مثل «[تکمیل شود]») در سایت با رنگ زرد نمایش داده می‌شوند تا دهیاری آن‌ها را کامل کند. بعد از هر ویرایش: `npm run build` و آپلود دوباره محتوای `out`.

## چه چیزهایی منتقل نشد

سایت وردپرس فعلی روی این بخش‌ها محتوای واقعی نداشت، بنابراین فقط صفحه معرفی آن‌ها ساخته شد:
- **ووکامرس:** هیچ محصولی ثبت نشده بود؛ صفحه فروشگاه به فرم استعلام وصل است. صفحه‌های سبد خرید / پرداخت / حساب کاربری ساخته نشدند.
- **تقویم رویدادها:** هیچ رویدادی ثبت نشده بود؛ صفحه پیام «هنوز رویدادی ثبت نشده» نشان می‌دهد.
- **گالری و تصاویر:** هیچ تصویری (حتی تصویر شاخص نوشته‌ها) در وردپرس نبود؛ لوگو و عکس‌ها باید از دهیاری گرفته شود.
- **تنظیمات Rank Math و پوسته Elementor** که ظاهر قبلی را می‌ساخت؛ ظاهر جدید با همان رنگ‌های سایت (سرمه‌ای، آبی، شنی) طراحی شده است.

اگر در آینده فروشگاه واقعی، رویداد با ثبت‌نام یا پنل مدیریت محتوا لازم شد، باید یک بک‌اند اضافه شود (مثلاً وردپرس headless یا یک CMS) و آن وقت Next.js روی سی‌پنل با **Setup Node.js App** اجرا شود؛ در آن حالت خط `output: 'export'` را از `next.config.mjs` بردارید.
